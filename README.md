## Daftar dan Deskripsi Folder

Berikut adalah rincian topik pembelajaran yang terdapat pada masing-masing folder dalam repository ini:

### 1. [02_Pemrograman_Javascript](https://github.com/davizofficial/KPL_Davis-Arvaputra-Dwiansyah-103122400034_SE-08-01/tree/main/02_Pemrograman_Javascript)
Berisi latihan dasar pemrograman JavaScript, pengenalan sintaksis, struktur data bawaan, dan kontrol alur pemrograman untuk memperkuat pondasi logika pemrograman web.

### 2. [03_GUI_dengan_HTML_dan_CSS](https://github.com/davizofficial/KPL_Davis-Arvaputra-Dwiansyah-103122400034_SE-08-01/tree/main/03_GUI_dengan_HTML_dan_CSS)
Membahas perancangan antarmuka pengguna grafis (GUI) berbasis web menggunakan teknologi HTML untuk struktur konten dan CSS untuk tata letak serta estetika visual.

### 3. [04_Automata_dan_Table-Driven_Construction](https://github.com/davizofficial/KPL_Davis-Arvaputra-Dwiansyah-103122400034_SE-08-01/tree/main/04_Automata_dan_Table-Driven_Construction)
Implementasi mesin keadaan (State Machine / Automata) dan teknik konstruksi berbasis tabel (Table-Driven Construction) untuk mempermudah pemeliharaan alur logika transisi state.

### 4. [05_Generics](https://github.com/davizofficial/KPL_Davis-Arvaputra-Dwiansyah-103122400034_SE-08-01/tree/main/05_Generics)
Penerapan pemrograman generik (Generics) untuk membuat kelas, antarmuka, dan fungsi yang fleksibel serta dapat digunakan kembali dengan tipe data yang berbeda tanpa mengorbankan keamanan tipe (type safety).

### 5. [06_Design_by_Contract_dan_Defensive_Programming](https://github.com/davizofficial/KPL_Davis-Arvaputra-Dwiansyah-103122400034_SE-08-01/tree/main/06_Design_by_Contract_dan_Defensive_Programming)
Implementasi metode Design by Contract (DbC) menggunakan prasyarat (preconditions), pascasyarat (postconditions), dan invariants, serta penerapan pemrograman defensif untuk mengantisipasi kesalahan input runtime.

### 6. [07_Grammar-Based_Input_Processing_Parsing](https://github.com/davizofficial/KPL_Davis-Arvaputra-Dwiansyah-103122400034_SE-08-01/tree/main/07_Grammar-Based_Input_Processing_Parsing)
Pengolahan input berbasis tata bahasa (grammar) dan teknik parsing data untuk memeriksa keabsahan struktur teks sesuai aturan sintaksis yang ditentukan.

### 7. [08_Runtime_Configuration_dan_Internationalization](https://github.com/davizofficial/KPL_Davis-Arvaputra-Dwiansyah-103122400034_SE-08-01/tree/main/08_Runtime_Configuration_dan_Internationalization)
Pengaturan konfigurasi dinamis aplikasi pada saat runtime serta penerapan fitur internasionalisasi (i18n) untuk mendukung lokalisasi bahasa dan format regional.

### 8. [09_API_Design&Construction_Using_Swagger](https://github.com/davizofficial/KPL_Davis-Arvaputra-Dwiansyah-103122400034_SE-08-01/tree/main/09_API_Design&Construction_Using_Swagger)
Perancangan, dokumentasi, dan konstruksi antarmuka pemrograman aplikasi (API) RESTful menggunakan standar OpenAPI dan spesifikasi Swagger.

### 9. [10_Library_Construction](https://github.com/davizofficial/KPL_Davis-Arvaputra-Dwiansyah-103122400034_SE-08-01/tree/main/10_Library_Construction)
Pengembangan modul kode terpisah dalam bentuk pustaka (library) eksternal yang siap didistribusikan dan digunakan kembali oleh aplikasi lain secara efisien.

### 10. [12_Performance_Analysis_Unit_Testing_dan_Debugging](https://github.com/davizofficial/KPL_Davis-Arvaputra-Dwiansyah-103122400034_SE-08-01/tree/main/12_Performance_Analysis_Unit_Testing_dan_Debugging)
Teknik analisis kinerja program, pembuatan skenario pengujian unit (unit testing), serta metodologi pelacakan dan perbaikan kesalahan (debugging) pada sistem.

### 11. [13_Design_Pattern_Implementation](https://github.com/davizofficial/KPL_Davis-Arvaputra-Dwiansyah-103122400034_SE-08-01/tree/main/13_Design_Pattern_Implementation)
Penerapan pola desain perangkat lunak (design patterns) standar industri seperti Creational, Structural, dan Behavioral patterns untuk mewujudkan arsitektur kode yang bersih dan terstruktur.

### 12. [14_Clean_Code](https://github.com/davizofficial/KPL_Davis-Arvaputra-Dwiansyah-103122400034_SE-08-01/tree/main/14_Clean_Code)
Implementasi prinsip-prinsip kode bersih (Clean Code) seperti pemisahan modul yang terfokus (Single Responsibility Principle), penghindaran kode duplikat, dan teknik refaktorisasi berkelanjutan demi meningkatkan kemudahan pembacaan (readability) dan pemeliharaan (maintainability) kode jangka panjang.
